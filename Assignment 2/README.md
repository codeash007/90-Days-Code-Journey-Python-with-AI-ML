# Python Assignment 02 – Loops & Logic 🐍

This folder contains solutions for **Assignment 2** of my Python learning journey.
The assignment focuses on strengthening logic building using loops, conditions,
and basic problem-solving techniques.

## 📌 Problems Covered

1. Counting number of digits in a given number
2. Calculating sum of digits of a number
3. Printing digits of a number
4. Printing even numbers within a range
5. Printing prime numbers in a given range
6. Number guessing game
7. Calculating final tax based on conditions

## 📂 Files Included

- `CountNumDigit.py` – Counts digits in a number
- `SumOfDigit.py` – Finds sum of digits
- `PrintDigitsNum.py` – Prints each digit of a number
- `PrintEven.py` – Prints even numbers
- `PrintPrimeNum.py` – Prints prime numbers in a range
- `NumGuessingGame.py` – Simple number guessing game
- `FinalTaxRate.py` – Calculates tax based on logic

## 🧠 Concepts Used
- for loop
- if / else conditions
- Modulus operator
- Range function
- Logical thinking

## 🎯 Objective
Improve problem-solving skills and build a strong foundation
in Python programming for **AI & Machine Learning**.
