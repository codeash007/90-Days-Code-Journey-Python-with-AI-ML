# Python Fundamentals – Assignment 01 🐍

This folder contains solutions to **Assignment 1** based on Python Fundamentals.
The assignment focuses on understanding core Python concepts such as input/output,
variables, type casting, arithmetic operations, and basic logic building.

## 📌 Problems Covered

1. Taking user name and age as input and printing a formatted message
2. Performing sum, difference, product, and quotient of two numbers
3. Converting integers and float to float and calculating average
4. Type conversion of string number to int, float, and string
5. Evaluating expressions using operator precedence
6. Swapping two numbers entered by the user
7. Converting temperature from Celsius to Fahrenheit
8. Calculating area of a circle using radius
9. Computing Simple Interest using Principal, Rate, and Time
10. Extracting integer and fractional part from a decimal number

## 🧠 Concepts Used
- Input & Output
- Variables
- Data Types
- Type Casting
- Arithmetic Operators
- Operator Precedence
- Mathematical Formulas

## 🎯 Objective
To build a strong foundation in Python programming for future learning in
**AI & Machine Learning**.
